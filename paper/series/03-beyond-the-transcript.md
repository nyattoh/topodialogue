# Paper 3 — Beyond the transcript

## Working title

**TopoDialogue III: Beyond the Transcript — Observable Implicit Interactional Structure in Human–AI Dialogue**

## 核となる問い

明示的な発話内容だけでは表しにくい相互作用の構造を、心理状態の推定なしに、注釈可能なイベントと軌跡として表現できるか。

## ここでいう「言語化されない部分」

本稿では、内面や無意識を意味しない。次のように、会話ログから観測または注釈できる相互作用イベントを指す。

- 発話の中断、再開、言い直し、自己訂正
- 明示的な拒否、保留、採用、再要求
- 同一語句・概念の再訪と、再訪時の機能の変化
- 主導権の移動、質問への応答、提案の採否
- 既出の説明に戻るが、制約や視点が変わる箇所

## 入力

- JSONまたはMarkdownの会話履歴
- 発話単位の話者、時刻、順序
- 可能なら編集履歴、再生成、コピー、採用、拒否などの操作イベント
- 人手注釈用の少量の代表ケース

## 表現

各発話を単語の集合として扱うのではなく、発話イベントと相互作用イベントを分ける。

```text
utterance -> semantic state -> interaction event -> trajectory edge
```

最小イベント型は `revisit`, `repair`, `rejection`, `adoption`, `handover`, `reframing`, `pause` とする。イベントに確信度と出典位置を付け、推測的なラベルは別枠で表示する。

## 評価

1. 同じ会話の再現性: 同一入力から同一イベント列と同一図が得られるか。
2. 注釈一致度: 2名以上の注釈者によるイベントラベルの一致度。
3. ベースライン比較: テキスト類似度だけの軌跡と、イベントを含む軌跡の差。
4. ループ・進展・脱出: 第2稿の指標を再利用し、イベント条件を追加したときの変化を報告。
5. 失敗例: 短文、引用、話者誤認、同語反復、編集履歴欠損、モデル出力の定型句。

## 明示的に主張しないこと

- 発話されていない心理内容を復元できる。
- 沈黙から感情や意図を決められる。
- 注釈イベントが話者の真の内面を表す。

## 完成ゲート

- イベントスキーマとサンプルデータが公開可能な形で揃う。
- 注釈手順、除外基準、注釈一致度が揃う。
- 少なくとも合成ケースと実会話ケースの双方で再現できる。
- 英日本文、参考文献、事実確認、図、再現手順が揃う。

既存の分析パイプラインに、出典位置付きイベントスキーマ、イベント列のJSON出力、イベント表示のON/OFF比較、注釈一致度計算を追加する。
