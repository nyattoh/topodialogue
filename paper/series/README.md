# TopoDialogue paper series

## 結論

現時点の「稿」は5つです。

- 第1稿: TopoDialogueの初期論考・実装基盤。既存の `paper/topodialogue-en.tex` と `paper/topodialogue-ja.md` を保持する。
- 第2稿: 再現可能な軌跡計測器。`paper/draft2/` と `paper/submission/topodialogue-draft2-source/` にある、arXiv投稿候補の独立したPhase-1論文。
- 第3稿: 観測可能な暗黙的相互作用構造。`paper/draft3/` と `output/zenodo/draft3/` に、実会話の全文非公開派生データを使った英日本文・PDF・再現用ソースがある。
- 第4稿: モダリティ来歴と変換損失の合成検証。`paper/draft4/` と `output/zenodo/draft4/` に、英日本文・PDF・再現用ソースがある。人手一致度と参加型レビューは未実施のため、計測器論文として主張を限定する。
- 第5稿: 主体性・表示主権・方略適応の構築ケース検証。`paper/draft5/` と `output/zenodo/draft5/` に、英日本文・PDF・再現用ソースがある。参加者実験は未実施のため、制御契約と算術の検証に主張を限定する。

論文シリーズ全体は、現段階では5本に固定する。これは「5本すべてを同じ日に完成扱いにする」という意味ではなく、各論文が前の論文の検証済み成果だけを引き継ぐための研究計画である。

## 依存関係

```text
第1稿（概念）
   ↓ 定義と問いを固定
第2稿（テキストから再現可能な軌跡）
   ↓ 基本指標・合成検証・失敗報告を確立
第3稿（観測可能な暗黙的相互作用）
   ↓ イベント化、人手評価、言語・条件別の可搬性境界を確立
第4稿（変換損失＋アクセシブルな複数経路）
   ↓ 元経路・変換損失・利用者訂正・文脈較正を確立
第5稿（相互作用方略の適応＋主体性・介入・豊かなトポロジー）
```

## 共通の執筆・検証規則

1. 主張は、観測できる入力、明示した変換、再現可能な出力に限定する。
2. 「意味」「感情」「主体性」を直接推定したとは書かない。必要な場合は、注釈可能な代理変数と限定条件を明示する。
3. 合成ケース、実データ、失敗例、表示アーティファクトを別々に報告する。
4. 形が面白いことを発見の根拠にしない。ループ、螺旋、脱出は、指標と比較条件で区別する。
5. 本文はイギリス英語で作成し、日本語版も同時に維持する。
6. arXiv投稿可能性は、本文、参考文献、図、再現手順、事実確認、ライセンス・個人情報確認が揃った時点で判定する。

## 完成ゲート

### 第1稿

- 概念の出典とTopoDialogue独自の定義が区別されている。
- 第2稿と矛盾する強い主張を残さない。

### 第2稿

- 既存の合成ケース6種がPASSする。
- ループ、進展、脱出の指標が計算できる。
- 図4点、英日本文、参考文献、事実確認、arXiv source packageが揃っている。
- PDFコンパイル環境が得られたら最終目視確認を行う。

### 第3稿

- 暗黙的という語を心理状態の推測に使わない。
- 発話イベント、修復、自己訂正、拒否、再訪、主導権交替を明示的に符号化できる。
- 人手注釈者間一致度と、本文だけを使うベースラインを報告する。

### 第4稿

- 第3稿のテキストイベントを基準に、文字化・正規化で失われる相互作用情報を測る。
- 音声、手話、記号、視線、スイッチ、触覚、AACを並列の一次経路として扱う。
- 同一文字列で韻律だけを変える既知合成ケースと、異なる経路間の変換損失を検証する。
- 個人内・関係内・状況内ベースラインを分離し、障害名や国籍から応答方略を固定しない。
- 利用者による訂正、拒否、削除、代替経路選択をイベント契約に含める。

### 第5稿

- ユーザーとAIの主導権を、観測可能な操作・提案・採用・拒否のイベントとして扱う。
- 適応対象を固定的な人格ではなく、特定状況での相互作用方略の結果として定義する。
- RAGは過去エピソードを取得する比較対象、グラフは関係を保持する表現手段とし、適応方略そのものと混同しない。
- 表示変換が解釈を誘導する可能性を実験的に評価する。
- Persistent Homologyやマルチエージェント構成は、実験で必要性が示された場合だけ導入する。

## 現在の着手点

第1〜5稿の公開候補一式を固定した。第5稿は、履歴なし、テキストRAG、イベントRAG、関係グラフ、ユーザー制御付き方略適応を分離し、採用、拒否、訂正、削除、停止と表示選択の契約を構築ケースで検証する。次の実証ゲートは、第3稿イベントの独立注釈者間一致度、対象経路を知る利用者による参加型レビュー、表示条件を比較する参加者実験である。これらが完了するまで、実環境の精度、アクセシビリティ効果、パーソナライズ効果、因果的な利益は主張しない。身体センサー、Persistent Homology、マルチエージェント、完全なTopoプロトコルは、必要性が示されるまで導入しない。
