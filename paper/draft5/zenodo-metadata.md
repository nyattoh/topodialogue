## Description

TopoDialogue V specifies an auditable control layer between dialogue-trajectory evidence and intervention. It separates no-history, text-RAG, event-RAG, relation-graph, and user-controlled strategy-adaptation conditions. Fifteen constructed episodes validate proposal, explicit adoption, rejection, correction, deletion, stopping, rendering choice, user-originated novelty, assistant-induced recurrence, burden, and a negative gate for unjustified richer topology. The release establishes arithmetic and control semantics only; it makes no participant, causal-benefit, diagnostic, cultural, disability, emotional, or stable-personality claim. Includes a British-English PDF, Japanese companion text, source, tests, figures, and constructed fixtures.
