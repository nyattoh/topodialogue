TopoDialogue second-draft arXiv source package

Main file: main.tex
Bibliography: references.bib
Figures: figures/*.png

Upload this directory as a source submission after endorsement for the chosen
arXiv category has been granted. The source package is self-contained; all
figure paths are relative to main.tex.

Before upload:

1. Compile main.tex locally with the same engine selected for arXiv.
2. Inspect every page of the generated PDF, including all four figures and the
   final references.
3. Confirm the title, author name, abstract, category, licence, and public
   contact details in the arXiv submission form.
4. Keep the Japanese manuscript and audit files outside this upload package.

This package deliberately makes no claim about natural-dialogue accuracy,
psychological-state inference, complete conversation export, or a topological
invariant. Those are outside the validated Phase-1 scope.
