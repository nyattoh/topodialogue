# TopoDialogue 協力依頼一式

最初に実施するのは、**合成会話だけを使う独立注釈パイロット**です。
実際の個人会話や、心理・病気・性格を推測する課題は含めません。

## 研究者が最初にすること

1. `00-settings-required-ja.md` の5項目を確定する。
2. 協力候補者ごとに、連絡先とは別の研究用IDを発行する。
3. 親しい相手には `01-annotation-dm-ja.md`、正式な依頼には
   `02-annotation-email-ja.md` を送る。
4. 同意前に `03-participant-information-annotation-ja.md` を渡す。
5. 同意確認後にだけ、素材、コードブック、回答ファイルを渡す。
6. 回答者同士をつながず、他の人の回答や自動抽出結果を見せない。

## ファイル

- `00-settings-required-ja.md` — 募集前に確定する設定
- `01-annotation-dm-ja.md` — LINE・DM向け短文
- `02-annotation-email-ja.md` — 正式メール
- `03-participant-information-annotation-ja.md` — 参加者向け説明
- `04-consent-annotation-ja.md` — 同意確認
- `05-instructions-annotation-ja.md` — 作業手順
- `06-reminder-and-thanks-ja.md` — 催促・辞退受付・お礼
- `07-display-study-invitation-ja.md` — 次段階の表示比較用（まだ送らない）
- `08-form-spec-ja.md` — フォーム作成時の項目一覧
- `09-coordinator-checklist-ja.md` — 研究者用チェックリスト
- `10-recruitment-tracker.csv` — 氏名・連絡先を書かない進行管理表
- `../templates/annotation-table.csv` — 表計算ソフト用回答テンプレート

## 最初の募集人数

まず候補者3人へ個別に依頼し、少なくとも2人が独立に完了するところまでを
手順確認の一単位とします。これは統計的に十分な本試験人数という意味では
ありません。途中でコードブックを変えた場合は、変更前後の回答を同じ版として
混ぜず、versionを上げて再実施します。

## 重要な境界

このパイロットは、ラベル定義と入力手順が理解できるかを確かめるものです。
人数が少ない段階の結果を、自然会話での精度、文化差、アクセシビリティ、
3D表示の有効性として報告しません。
