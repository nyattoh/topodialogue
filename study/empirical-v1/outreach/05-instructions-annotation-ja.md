# 独立注釈 作業手順

## 受け取るもの

1. 合成会話ファイル
2. `annotation-codebook-ja.md`
3. あなた専用の回答ファイル
4. この手順書

## 作業前

- 回答ファイルの `annotator_id` が割り当てられた研究用IDであることを確認する。
- 氏名やメールアドレスを書かない。
- 他の回答者の回答や、自動判定結果を見ない。
- コードブックversionが `1` であることを確認する。

## 発話ごとの注釈

各発話について、当てはまるラベルへ `1`、当てはまらない場合は `0` を記入
します。一つの発話に複数ラベルを付けて構いません。

- `revisit`：以前の問い・制約・話題領域へ明示的に戻る
- `repair`：表現を訂正・言い換え・限定する
- `rejection`：提案や進め方を明示的に採用しない
- `adoption`：提案や進め方を明示的に採用する
- `handover`：次の選択を相手へ渡す
- `reframing`：異なる問い・制約・抽象度から捉え直す
- `pause`：停止、待機、保留、後で戻ることを明示する

感情や意図を想像して付けないでください。書かれている発話に根拠がない場合は
`0` とし、迷った理由を `notes` に書きます。

## 区間全体の注釈

指定された区間に対して、次から一つを選びます。

- `closed_loop`
- `spiral_revisit`
- `escape`
- `open_trajectory`
- `ambiguous`

「良い・悪い」ではなく、コードブックの操作的定義に従ってください。証拠が
不足または競合する場合は `ambiguous` を選びます。

## 提出前チェック

- [ ] 全行を確認した
- [ ] 氏名・メールを書いていない
- [ ] 他の回答を見ていない
- [ ] 自動判定を見ていない
- [ ] 迷った箇所を推測で埋めず、notesに記録した

提出後も、削除受付期限までは研究用IDを使って回答削除を依頼できます。
