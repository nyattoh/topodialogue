# 研究者用チェックリスト

## 募集前

- [ ] 研究責任者名と問い合わせ先を確定した
- [ ] 謝礼、保管期間、削除期限を確定した
- [ ] 倫理審査状況を事実どおり記載した
- [ ] 合成会話だけを使うことを確認した
- [ ] codebook version 1を凍結した
- [ ] 研究用IDを発行した
- [ ] 連絡先対応表を回答データと分離した
- [ ] 同意未確認の相手へ課題を送らない手順にした

## 配布時

- [ ] 説明文を先に送った
- [ ] 質問する機会を設けた
- [ ] 同意を確認した
- [ ] 相手専用の研究用IDを設定した
- [ ] 他回答者の結果と自動判定を含めていない
- [ ] 回答期限と削除期限を区別して伝えた

## 回収時

- [ ] 氏名、メール、自由記述中の個人情報を確認した
- [ ] case ID、annotator ID、codebook versionを検証した
- [ ] `independent_before_adjudication=true` を確認した
- [ ] 合議前ファイルを読み取り専用で保存した
- [ ] 欠損・辞退・削除を理由付きで記録した
- [ ] 催促は一度だけにした

## 分析時

- [ ] 二人以上の回答が揃う前に自動結果へ合わせて定義を変えていない
- [ ] `adjudicate` で同数票を未解決のまま出力した
- [ ] 未解決ラベルを人間が確認し、元ファイルを上書きしていない
- [ ] kappa計算不能を完全一致と書いていない
- [ ] パイロットを一般化可能な精度として報告していない

## 公開前

- [ ] 生会話、氏名、メール、対応表が含まれない
- [ ] 削除要求を反映した
- [ ] 人数、除外、欠損、低一致、null結果を記載した
- [ ] 合成・パイロット・本試験を明確に区別した
- [ ] 3D表示やパーソナライズの効果を未測定のまま主張していない
